# 数学一考试定位与知识地图使用说明

本项目不是简单教材目录，而是把每个节点拆成：

- 知识对象；
- 方法入口；
- 使用条件与禁用边界；
- 可复核的验收证据。

## 三大板块

- 高等数学：G1-G11。
- 线性代数：L1-L6。
- 概率论与数理统计：P1-P8。

## 能力层级

- A：基础定义、公式、计算、条件判断。
- B：跨章节、参数、证明、常规综合。
- C：陌生结构、长证明、限时区分度题。

90天先做完A，再用B拉分，C选择性突破。

## 使用每个章页

先修 → 节点表 → 方法入口 → 边界条件 → 示例 → 闭卷验收 → 隔日复测 → 真题迁移。

## 容量说明

一个节点不是一整天或一节长课；有基础的可以短诊断快速过，没有基础的再拆小。186是可追踪清单，不是要求186次课。A/B仅表示教学顺序，不是官方难度或考频。

新题入口见[[01-知识地图/06-方法选择路线]]；现阶段讲课顺序见[[G3教学路线]]。
