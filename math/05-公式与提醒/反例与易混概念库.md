# 反例与易混概念库

| 错误推断 | 反例/修正 |
|---|---|
| 有界必收敛 | (−1)^n |
| 单调必收敛到有限值 | a_n=n |
| 振荡必无极限 | (−1)^n/n→0 |
| 左右极限相同且该点有定义就连续 | x≠0时0，x=0时1 |
| 连续必可导 | abs(x)在0 |
| 可导必导函数连续 | x²sin(1/x)，补f(0)=0 |
| 导数0必极值 | x³在0 |
| 极值点必须可导 | abs(x)在0 |
| 二阶导0必拐点 | x⁴在0 |
| 分母0必垂直渐近线 | (x²−1)/(x−1)在1只是孔洞 |
| 等价可直接替换任何加减项 | ((x+x²)−x)/x²，正确极限1，粗替换误得0 |
| 原比极限存在必导数比存在 | f=x+sin x,g=x在∞：原比→1，导数比1+cos x无极限 |
| 偏导存在必连续 | f=xy/(x²+y²),f(0,0)=0：原点两偏导0但沿y=x不连续 |
| 同秩向量组必等价 | span(1,0)与span(0,1)同维但不同空间 |
| 重特征值必不能对角化 | 单位矩阵 |
| 相同特征值必相似 | 单位矩阵与[[1,1],[0,1]] |
| 正定判定把所有>改≥就是半正定 | diag(0,−1)顺序主子式0、0却非半正定 |
| 不相关必独立 | X均匀(−1,1)，Y=X² |
| 密度值不能大于1 | 均匀(0,1/2)密度为2 |
| 概率0事件一定不可能 | 连续变量取某确定值可有概率0 |
| 通项趋0则级数收敛 | 调和级数 |
| 未拒绝H0就是证明H0 | 只是现有证据在该水平下不够拒绝 |

使用方式：先解释为什么反例满足前件而不满足后件，再做条件修复。反例背出来但不能解释，仍只记E2。
