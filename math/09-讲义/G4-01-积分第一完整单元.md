# G4第一完整单元｜从求导反推积分：基本公式、换元、分部与定积分

本单元是系统恢复，不是完整G4结课。建议一次读完方法框架，再合上讲义做整组题；无需每看一行就回复。当前只到基础换元/分部，复杂有理函数、第二换元、反常积分等留后续。

## 目标

能回答“我为什么选换元/分部”；能把结果写完整；能用求导检查。不只会看提示填u，也不因漏一个+C就无限重复整节。

## 一、积分在求什么？

在一个区间上，若F'(x)=f(x)，F是f的一个原函数。不定积分表示一族原函数：

$$\int f(x)\,dx=F(x)+C.$$

例如x²、x²+3、x²−8求导都是2x，所以∫2x dx=x²+C。C不是装饰，它代表所有可能的常数差。

两条规则：线性拆分；求导验算。$\int(af+bg)dx=a\int fdx+b\int gdx$，最后合并为一个任意常数即可。

## 二、基础积分表：本次先稳住六组

| 被积函数 | 一个原函数（写不定积分时再加C） | 条件 |
|---|---|---|
| x^n | x^(n+1)/(n+1) | n≠−1；在函数有意义的区间 |
| 1/x | ln(abs(x)) | x≠0，不跨0讨论 |
| e^(ax) | e^(ax)/a | a为非零常数 |
| cos(ax) | sin(ax)/a | a≠0 |
| sin(ax) | −cos(ax)/a | a≠0 |
| 1/(1+x²) | arctan x | 全体实数 |

尤其记清：**积分cos得到+sin；积分sin得到−cos。**∫cos(3x)dx还要除3，因为求导会乘3。

$\ln|x|$的绝对值用于覆盖x<0的区间；如果题目已给x>0，或内部表达式恒正，可简写ln正表达式。不同不相连区间的常数不必相同。

## 三、第一换元：把链式求导倒过来

链式求导是$[F(g(x))]'=F'(g(x))g'(x)$，反过来就得到换元积分。

### 识别办法

先找“内部函数”，再看外面是否出现它的导数；差常数倍，可以提出来补齐。

**例1：**$\int x e^{x^2}\,dx$。

内部是x²，导数是2x，外面只有x，因此差一个1/2：

$$u=x^2,\quad du=2x\,dx,\quad x\,dx=\tfrac12du,$$
$$\int xe^{x^2}dx=\tfrac12\int e^u du=\boxed{\tfrac12e^{x^2}+C}.$$

验算：导数为$(1/2)e^{x²}\cdot2x=xe^{x²}$。

**例2：**$\int 2x/(1+x^2)\,dx$。

令u=1+x²，du=2x dx：
$$\int\frac{2x}{1+x^2}dx=\int\frac{du}{u}=\ln|u|+C=\boxed{\ln(1+x^2)+C}.$$

因为1+x²>0，最后无需绝对值。

### 边界

换元后必须把整个被积表达式与dx换干净，不能混着u与未替换的x。没有导数配对时别硬凑；∫xe^x就不会因为“有指数”自动成为好换元题。

## 四、分部积分：把乘积求导倒过来

由$(uv)'=u'v+uv'$，积分并移项：

$$\boxed{\int u\,dv=uv-\int v\,du}.$$

### 怎么选u和dv？

- u选求导后更容易处理的部分。
- dv选容易积分的部分。
- 看剩下的∫v du是否真的更简单；不是只要相乘就必须分部。

### 你刚才不知道的题：∫x ln x dx，x>0

ln x求导变1/x；x容易积分。选择：

$$u=\ln x,\quad dv=x\,dx,\quad du=\frac{dx}{x},\quad v=\frac{x^2}{2}.$$

代入：

$$\begin{aligned}
\int x\ln x\,dx
&=\frac{x^2}{2}\ln x-\int\frac{x^2}{2}\frac1x\,dx\\
&=\frac{x^2}{2}\ln x-\frac12\int x\,dx\\
&=\boxed{\frac{x^2}{2}\ln x-\frac{x^2}{4}+C}.
\end{aligned}$$

关键收益：原本带ln的积分，变成了简单多项式积分。

验算：第一项求导为x ln x+x/2，第二项求导为−x/2，两项抵消后回到x ln x。

**另一个常见入口：**∫ln x dx可以看成∫1·ln x dx，选u=ln x、dv=dx，也可用分部。不是只有题面明显写出两因子才可用。

## 五、怎样选方法？两题放一起比较

| 题目结构 | 优先尝试 | 理由 |
|---|---|---|
| xe^(x²) | 换元 | x与内层x²的导数配对 |
| xe^x | 分部 | x求导变1，e^x易积分 |
| 2x/(1+x²) | 换元 | 分母导数出现在分子 |
| x ln x | 分部 | ln求导变1/x，与v中的x²简化 |

这些是优先尝试方向，不是唯一合法方法。判断关键是**变形之后是否更简单**，不是机械认“长得像”。

## 六、定积分：有上下限时多做什么？

若f连续且F'=f：

$$\int_a^b f(x)dx=F(b)-F(a).$$

不定积分给一族函数；定积分给一个数。定积分结果不写+C，因为上下限的常数抵消。

例：
$$\int_0^1\frac{2x}{1+x^2}dx=[\ln(1+x^2)]_0^1=\ln2.$$

若用u=1+x²，x=0对应u=1，x=1对应u=2，直接算$\int_1^2du/u=\ln2$。**换变量就换限，或者换回x后用原限；两种合法方式别混用。**

## 七、每题只写三行，够用且可检查

1. 选法与理由：内部导数配对 / 一项求导更简单。
2. 关键变形：u、du，或u、dv、du、v。
3. 结果与核对：+C/合法区间；不定积分验导，定积分核上下限。
