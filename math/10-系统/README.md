# 数学一项目系统层

这是长期维护层，不是学习内容层。它把“教学、出题、批改、证据、进度、复习、Git同步”分开，避免项目继续只靠聊天记忆。

## 目录

- `技能注册表.md`：项目本地技能/工作流如何被选择。
- `工作流/`：开场、教学块、预测、批改、收尾、复盘的固定协议。
- `schemas/`：JSON 数据最低结构；不替代人工判断。
- `tools/validate_math_project.py`：本地健康检查。
- `skills/`：三个项目本地 Codex skill 模块；通过根 `AGENTS.md` 路由，不覆盖全局 skill。
- `清单/`：长期复盘、迁移、资料和版本清单。

## 单一事实源

```text
节点掌握       -> 06-测试与掌握度/节点台账.json
当前流程状态   -> project-state.json
原始作答       -> 06-测试与掌握度/作答记录/*.json
事前预测       -> 06-测试与掌握度/出题预测/*事前预测.json
预测结果       -> 06-测试与掌握度/出题预测/*结果.json
人类可读镜像   -> README、总进度看板、矩阵、节点台账.md、每日记录
历史归档       -> 99-归档/（压缩文件默认不入Git）
```

## 重要区分

- 任务执行完成 ≠ 知识掌握。
- 讲义后复现 ≠ 未见题迁移。
- 主体正确 ≠ 完整正确。
- 有记录 ≠ 预测能力或考试分数。
- 单元收尾 ≠ 全天结束。
