# 长期维护清单

## 每次学习后

- [ ] 原答/题目/是否提示/用时已记录
- [ ] 节点台账与章页镜像一致
- [ ] 错题和复习日已更新
- [ ] 今日任务状态与实际质量分开
- [ ] 续接说明指向真实下一题

## 每周

- [ ] 线代、概率是否有实际触达
- [ ] 过期复习是否按优先级处理
- [ ] 预测只纳入条件可比的新题
- [ ] 计划是否超出真实容量
- [ ] Git变更是否只包含本次数学任务

## 发布/推送前

- [ ] 压缩归档未被暂存
- [ ] 常见凭据扫描无命中
- [ ] JSON可解析
- [ ] 节点数与镜像一致
- [ ] 内链与答案路径有效
- [ ] `git diff --check`
- [ ] 推送后本地HEAD=origin/main
