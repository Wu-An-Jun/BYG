# 项目本地 Skills

这些 `SKILL.md` 是 BYG 数学项目的可审计技能模块。它们属于项目工作流，不等同于全局 `$CODEX_HOME/skills`；本项目通过根 `AGENTS.md` 和 `10-系统/技能注册表.md` 路由加载。

- `math-study-orchestrator`：完整学习块与每日流程。
- `math-assessment-calibrator`：事前概率、批改、结果校准。
- `math-project-maintainer`：状态、镜像、链接、JSON和Git维护。

不要在技能中保存学生答案、凭据、压缩备份或临时输出；技能只保存规则和可复用流程。
