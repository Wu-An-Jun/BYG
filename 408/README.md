本项目只覆盖：

1. 数据结构
2. 计算机组成原理

## 如何使用

### 每次学习前

1. 先读取 `学习记录/总进度与今日看板.md`、当前每日计划和 `学习记录/当前状态.md`。
2. 只从当前最优先的节点开始，不凭感觉跳章节。
3. 先回忆和作题，再讲解；不能把“看懂”当成“会做”。

### 新增日常入口

- `学习记录/总进度与今日看板.md`：整体位置、今日已做与剩余。
- `学习记录/每日计划/Day02.md`：今天的固定任务、变更与结束条件。
- `学习记录/每日计划与预测协议.md`：开场计划、整组教学、每题预测与批改。
- `数据/每日任务.csv`、`数据/预测与表现.csv`：进度和事前预测主记录。

### 每次学习中

每个知识点都要记录四类证据：

- **概念**：能否用自己的话说清楚定义和边界。
- **机制**：能否解释为什么这样做、各步骤如何衔接。
- **计算/推导**：能否独立完成典型计算。
- **应用/代码**：能否解决题目或写出关键算法步骤。

### 每次学习后

更新：

- `学习记录/当前状态.md`
- `数据/知识点状态.csv`
- `学习记录/错题与复测.md`
- `学习记录/学习日志.md`

## 掌握等级与当前证据

- **U / ⚪ 未测**：无可靠作答证据，不等于不会。
- **F / 🔴 待修复**：已测出核心错误但尚未修复。
- **R / 🟡 恢复中**：初筛通过、提示后能做或刚纠正，尚未跨天验证。
- **V / 🟢 跨天验证**：满足无提示、不同题型和实际隔天条件。
- **S / 🔵 稳定验证**：在 V 基础上，约一周后的混合变式仍通过。
