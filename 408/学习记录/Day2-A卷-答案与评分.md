## Q1：分页（OS15）

4 KiB = 4096 B = 2^12 B，因此低12位为页内偏移。

- 页号：`0x5 = 5`；页内偏移：`0xA3C = 2620 B`。
- 页框18 = `0x12`；物理地址 `18×4096+2620 = 76348 = 0x12A3C`。
- 逻辑页号用来查页表，物理页框号用来拼接物理地址，偏移不变。

评分：页号和偏移均正确1分；页框映射、物理地址及解释正确1分。用页号5替代页框18是核心概念错误，无论总分多少都要修复。

## Q2：CPU性能（CO02）

- A：`1.2×10^8×1.5/(2.4×10^9)=0.075 s=75 ms`。
- B：`1.2×10^8×2/(3×10^9)=0.08 s=80 ms`。
- A更快；同一任务的性能与执行时间成反比，`性能A/性能B=时间B/时间A=80/75=16/15≈1.067`。

说“A的性能约为B的1.067倍”比“快1.067倍”更不歧义；A相对B用时减少6.25%，A相对B性能提高约6.67%，二者分母不同。

评分：公式和单位正确0.5分；两时间均对0.5分；优劣和倍数解释正确1分。

## Q3：信号量（OS09）

初值 `empty=6, full=4, mutex=1`。

```text
生产者：生产产品 → P(empty) → P(mutex) → 放入缓冲区 → V(mutex) → V(full)
消费者：P(full) → P(mutex) → 取出产品 → V(mutex) → V(empty) → 使用产品
```

消费者完整取出一次后：`empty=7, full=3, mutex=1`。

反例：缓冲区满时，生产者持有mutex后阻塞在empty；消费者无法进入临界区取出产品并释放empty，形成相互等待。该先后规则针对这个有界缓冲区模型，不能生搬为所有同步程序的唯一顺序。

评分：初值0.5分；两流程正确0.5分；完整操作后的计数0.5分；能构造满缓冲区死锁情景0.5分。临界执行中不应机械假定empty+full一直等于容量。

## Q4：Cache（CO14）

- 数据容量 `16×1024=2^14 B`，块大小 `32=2^5 B`。
- 行数 `2^14/2^5=2^9=512`。
- 位宽：Tag18、行索引9、块内偏移5，共32位。
- 地址 `0x12345=74565`。主存块号 `74565 div 32=2330`，偏移 `74565 mod 32=5`。
- 行索引 `2330 mod 512=282=0x11A`；Tag `2330 div 512=4`。
- 验算：`((4×512)+282)×32+5=74565`。

评分：行数及三段位宽正确1分；具体地址三段值及过程正确1分。

迁移练习（不计原分）：同数据容量与块大小改为4路组相联，共128组，组索引7位，Tag20位，偏移5位。此题“路数”改变组数而不改变总行数。

## Q5：补码（CO05）

```text
  0110 0100  (100)
+ 0011 1100  (60)
= 1010 0000  (保留8位)
```

位串按8位补码解释为 `160-256=-96`。真实数学结果160超过[-128,127]，两个正数相加得到负号，因此OF=1。加法结果小于256，没有最高位向外进位，所以CF=0。有符号溢出与无符号进位是不同问题。

评分：输入/结果位串0.5分；有符号结果0.5分；OF与CF及解释1分。

## N1：时延（CN02）

发送时延 `12000/(6×10^6)=2 ms`。
传播时延 `600000/(2×10^8)=3 ms`。
从首比特开始发送到末比特到达为 `2+3=5 ms`。
数据减半后，发送1 ms，传播仍3 ms，总4 ms。此题只有一条链路且忽略处理排队，不能推广为所有网络总时延公式。

## D1：数组删除（DS03 / DS33）

```c
int remove_x(int a[], int n, int x) {
    int k = 0;
    for (int i = 0; i < n; ++i) {
        if (a[i] != x) {
            a[k++] = a[i];
        }
    }
    return k;
}
```

循环开始时，`a[0..k)`恰为原数组已扫描部分`[0..i)`中不等于x的元素，且保持顺序；`k≤i`保证覆盖写不会破坏尚未读取的元素。结束时i=n，不变量直接给出结果。

| 输入 | x | 新长度 | 有效前缀 |
|---|---|---|---|
| 空数组 | 2 | 0 | 空 |
| [2,2,2] | 2 | 0 | 空 |
| [1,3,4] | 2 | 3 | [1,3,4] |
| [2,1,2,3,2] | 2 | 2 | [1,3] |

时间O(n)、辅助空间O(1)，稳定保留次序。尾部不清理不构成错误。代码示例已做构建侧边界检查，但**这不是学习者已会写代码的证据**。

教学评分另计6分：逻辑2、不变量1、四类边界1、复杂度1、C表达1。关键是能独立写和解释，不是背这段代码。
