# 每日计划、总进度与预测协议

生效：2026-09-18，依据学习者在Day2明确提出的要求。此协议优先于旧版“一次一道、逐点纠错”的教练流程。

## 1. 固定教学方式

**完整知识块 → 方法选择表 → 一组综合题 → 一次性批改 → 更新进度。**

不把知识块拆成连续小问等待回复，不在每次答错后无限插入局部小题。练习按主流程组织，附加量明确标为附加问题；题量不能靠增加机械填写字段来凑数。一个块批改后最多安排一次成组收尾，仍有错误则记录下次回访，不追求当场零错误。

## 2. 每日开始必须先展示计划，未展示不得开始出题

读取总进度、昨日结算、知识主表、错题和到期队列，再给出：

1. 整体阶段，以及四科各自的位置。
2. 今天的优先目标（原则上最多3个核心任务），为什么现在学它、与后续哪个节点有关。
3. 各任务的完整知识块范围、预计耗时、完成标准和验收标准。
4. 今日必做 / 有余力选做 / 明确不做。
5. 完成后如何判断今天可以结束。

确认实际可用时长。没有时长时可提出明确标注的暂定计划，但不能假定学习者承诺两小时。计划制定后固定任务ID和分母；新增、删减、延期必须写变更原因与版本，不能悄悄修改进度分母。

Day编号是学习会话序号，不自动等于相邻日历日期。跨天保持按实际日期核实。

## 3. 两种进度分开显示

### 任务执行进度

未开始 / 进行中 / 已完成 / 延期 / 取消。

“任务已完成”表示约定的成组作答、批改和下一步登记完成，不要求全对。“知识验收通过”则按正确过程与规定标准另行判断。未交的题保留未完成，不能自动判错；到时正式延期时要显示延期，不能当作已完成。

### 知识证据进度

U未测 / F待修复 / R恢复中 / V跨天验证 / S稳定验证，仍按原掌握协议执行。

显示各科节点总量、有证据节点和V/S数量，不把节点数量折算考试分值或“学完百分比”。范围核验尚未完成，不能把110个工作节点声称为官方完整考点清单。

## 4. 每道新题出题前记录正确概率

预测对象定义为：**在题目指定条件下，第一次提交该题完整答案且所有核心评分点正确的概率**。每题必须注明：

- 题目ID与关联节点；
- 条件：无提示/可看方法表/刚讲后练习/隔天复测；
- 正确概率p（0到1），展示百分数，初期取5个百分点的刻度，避免伪精确；
- 信心：低/中/高，及误差可能很大的原因；
- 依据：已有哪次作答、目标技能、步骤数、是否改变题型；
- 预先固定的核心评分点。

先确定完整题面，再估计并写入；发题前冻结，并在题目前向学习者展示（可放同一表，不一题一问）。不能看到答案后改写原p，也不能提前向学习者提示该题的解法或具体易错位置。更详细依据可在批改时展开。

本项目尚无经过验证的统计预测模型。初期是教练主观估计，不是个人能力常数、智力评估或408预测分。正确概率也不等于预期得分率。

## 5. 作答后怎样更新

同一批次一次性提供：预测p → 实际完整正确/部分正确/未完成 → 原始过程与错误原因 → 下一次预测如何调整。

- 已完整作答但核心错误：完整正确指标y=0；完整正确为y=1。
- 未作答、部分未提交、中途退出、条件改变：不默认y=0；记缺失/排除原因，另保留可评价的步骤证据。
- 同一道题经讲解后改对，只记纠错，不覆盖首答；下一道新的同类题才产生新预测。
- 不用一次错误大幅推断整科退步。区分位数/商余拆分、查表、地址合成、单位与题目组织负担。
- 历史题没有提前预测，p必须留空。严禁补写“当时我预计70%”。

## 6. 校准检查

当前合格的“预测—结果”样本为0，不能给出校准准确率。

初期逐题看方向性偏差。累计约20条条件可比、答案完整、提前冻结p的记录后，再做第一轮描述性检查（20是项目管理阈值，不保证统计可靠）：展示样本数，比较预测均值与实际完整正确率；按练习条件分组；可记录Brier分数 mean((p-y)^2)，不拿小样本作确定能力结论。

如果预测偏差主要集中在题目过长或步骤过多，优先调整题目组织，而不是把一切解释为学生知识差。

## 7. 每个知识块结束的固定反馈

今日任务：已完成 / 进行中 / 未开始 / 延期。
本块：学了什么、实际做了什么、哪一步已对、哪一步仍错。
预测对照：只比较真正提前登记的预测。
剩余：还差哪一组任务、预计多久（估计而非计时事实）。
下一步：唯一接续任务，不能突然换科或追加任务。

## 8. 每日结算

给出“今天是否完成”的明确结论，并分列：执行完成情况、验收通过情况、未完成与延期、四科状态变化、明日入口。新题必须绑定当天任务，不把聊天内容量当学习进度。不设后台提醒，除非学习者另行要求。
