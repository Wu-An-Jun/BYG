# 阶段路线与调整规则

## 先确认约束，不制造精确日历

原教师安排过 90 天与两小时学习，但目前未核实学习者的真实时长、目标分数和考试年份。以下是里程碑路线，不是“90 天保证提分”的承诺，也不是四科完成百分比。

| 阶段 | 目的 | 出口证据 | 未达到时怎么处理 |
|---|---|---|---|
| M0 接管与诊断 | 识别真实起点和遗忘点 | Day2复测原答；四科分块初测；确认可用时间 | 不把未测当不会；拆成多次短测 |
| M1 四科主干恢复 | 补齐前置概念与典型题能力 | 节点覆盖记录；基本算题和代码独立完成 | 缩小新课范围，补前置依赖 |
| M2 章节综合与迁移 | 从单点答案转为完整解题 | 不同题型、跨章节计算、算法书面表达 | 每次定位一个主要错误链 |
| M3 真题训练 | 适应题面、评分点和时间分配 | 可核验题源、逐题得分与用时、错因统计 | 不以“刷完一套”替代分析 |
| M4 限时整卷与回补 | 验证总表现并守住基础 | 多次完整限时记录及复盘 | 用失分证据调整，而非临考追新知识 |

## 第一个学习循环（学习次数，不等同日历天）

1. Day2：先做旧知识混合复测；余力允许才做时延或数组代码。
2. 下一次：回测分页与Cache；计网时延 → 子网；新增内容不超过两个小模块。
3. 再下一次：数组代码边界 → 链表/栈队列小诊断；穿插CPU/补码复测。
4. 后续一次：进程状态/调度小诊断，决定OS进入点。
5. 一周左右：四科混合回访并重新排序。未在前几次学习的内容不强行纳入这次回测。

## 可用时长的调整

- 30分钟：5分钟回忆 + 10分钟复测/批改 + 10分钟修复 + 5分钟记录；不强开新课。
- 60分钟：15分钟复测 + 25分钟一个新模块 + 15分钟独立练习 + 5分钟结算。
- 120分钟（仅示例）：20分钟复测 + 40分钟计网 + 35分钟数组/C表达 + 15分钟结算 + 10分钟休息。

如果分页/Cache/PV存在核心错误，先修复，压缩或取消新内容；疲劳或用时超限就停止，不产生“明天必须双倍补课”的隐性债务。

## 如何统计而不误导

统计独立首次正确率、关键步骤正确率、无提示变式通过率、错题复发和耗时；每次显示样本数。提示后改对与首次正确分开记。几道题只用于选择下一步，不能换算成真实408预测分。

知识节点粒度不同，110个节点不是等分权重。当前的证据数量不是备考完成百分比。
