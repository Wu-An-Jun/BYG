# 计算机网络｜知识地图与能力清单

## 学科主线

```text
网络指标/分层
  ↓
物理层传输 → 数据链路可靠传输/介质访问
  ↓
IP/路由/子网 → TCP/UDP
  ↓
DNS/FTP/邮件/HTTP
```

## 时延计算必须分清

```text
发送时延 = 分组长度 / 发送速率
传播时延 = 链路长度 / 传播速率
总时延还可能包含：处理时延、排队时延、重传等待等
```

不要把“发送得快”误认为“传播得快”：发送时延与数据量和发送速率有关，传播时延与距离和介质传播速率有关。

## 子网与路由的固定流程

1. 写出 IP 地址和掩码的二进制边界。
2. 判断网络号、子网号、主机号。
3. 求网络地址、广播地址、可用主机范围。
4. 对每条路由做最长前缀匹配。
5. 最后再判断下一跳和出接口。

## 负责人的检查点

- 先定位层，再套协议，不把 ARP、DNS、DHCP、ICMP 混为“都是 IP”。
- TCP 的可靠性、流量控制、拥塞控制必须分开解释。
- GBN 和 SR 的确认、重传、接收窗口不能凭印象。
- 子网题每一步都写掩码，不只看十进制地址。
