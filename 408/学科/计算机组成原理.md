# 计算机组成原理｜知识地图与能力清单

## 学科主线

```text
数制/编码
  ↓
补码与运算 → 浮点数
  ↓
性能指标 → 存储层次 → Cache/TLB → 指令与寻址
  ↓                                  ↓
CPU/数据通路 → 流水线/冒险 → 总线与 I/O
```

## 章节推进与题型

| 模块 | 核心产出 | 计算/判断重点 |
|---|---|---|
| 系统概述 | 能解释程序如何执行 | CPU 时间、CPI、主频、性能比较 |
| 数据表示 | 能完成编码与运算 | 进制、补码范围、溢出、IEEE754 |
| 存储层次 | 能完成地址和命中分析 | 容量、地址线、Cache 映射、替换、写策略 |
| 指令系统 | 能完成寻址和机器级理解 | 指令格式、有效地址、大小端、对齐 |
| CPU | 能画出执行路径 | 取指执行、控制信号、中断、异常 |
| 流水线 | 能计算周期与冒险代价 | 加速比、吞吐率、停顿、旁路、分支 |
| 总线/I/O | 能比较 I/O 方式 | 查询/中断/DMA、中断响应、总线事务 |

## 必须固定的公式与判定

```text
CPU 执行时间 = 指令数 × CPI × 时钟周期
             = 指令数 × CPI / 主频

Cache 地址划分：块内偏移 → 组索引 → Tag

物理地址（分页）= 物理页框号 × 页大小 + 页内偏移
```

## 负责人的检查点

- 计算前先统一单位：bit/Byte、ns/us/ms、MHz/GHz。
- 任何 `2^n` 都先写出 n 的来源，不凭口算猜。
- Cache 题先写“主存块大小、Cache 行数/组数、地址位数”，再拆位。
- 性能比较必须说明“比较的是执行时间、吞吐量还是加速比”。
- 补码溢出要依据符号位逻辑，不用“结果超出直觉范围”代替判定。
