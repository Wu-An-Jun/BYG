# 数据结构｜知识地图与能力清单

## 学科目标

不是只会背结论，而是要能在 C/C++ 语境下完成：结构选择、操作实现、复杂度分析、算法正确性说明和题型迁移。

## 章节推进图

```text
复杂度
  ↓
线性表 → 栈/队列/数组
  ↓             ↓
树/二叉树 → 堆/并查集 → 图
  ↓                         ↓
查找 ← 搜索树/散列/KMP ← 排序
```

## 重点能力矩阵

| 模块 | 必须做到 | 典型易错点 |
|---|---|---|
| 复杂度 | 能从循环、递归、嵌套结构判断复杂度 | 把顺序相加、循环相乘、递归展开混淆 |
| 线性表 | 能写顺序表/链表插入删除并处理边界 | 头结点、空表、尾结点、指针断链 |
| 栈队列 | 能判断合法序列、实现循环队列 | 栈顶方向、队列判空判满、模运算 |
| 树 | 能算结点/边/高度，完成遍历和重构 | 层数从 0/1 开始、遍历顺序错 |
| 堆 | 能判断建堆、插入、删除堆顶过程 | 大根堆/小根堆方向混淆 |
| 图 | 能选择 DFS/BFS、MST、最短路算法 | 算法适用条件、visited 更新时机 |
| 查找 | 能比较 BST/AVL/Hash/B/B+ | 平衡条件、冲突处理、查找长度 |
| 排序 | 能比较稳定性、复杂度和适用场景 | 最好/最坏情况、趟数、稳定性 |
| C/C++表达 | 能把思路写成可执行伪代码或关键代码 | 数组越界、循环边界、指针和返回值 |

## 后续最小训练单元

每次训练一个“结构 + 算法 + 复杂度 + 边界”闭环：

1. 先闭卷写出结构定义和操作不变量。
2. 再做一道小规模手算题。
3. 再写关键代码或伪代码。
4. 最后解释复杂度和最容易错的边界。

## 不允许的假掌握

- 只看遍历结果，不画树或不解释递归过程。
- 只背排序复杂度，不知道比较/移动发生在哪里。
- 只会数组题，不会说明为什么链表或堆更合适。
- 代码能跑一次就认为算法正确，不检查空输入、单元素和极端边界。
